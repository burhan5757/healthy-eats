# Design handoff

Drop landing-page design screenshots (or exported HTML) in this folder.

**Naming:** `landing-01.png`, `landing-02.png`, … in top-to-bottom order of the page.
Full-page captures are ideal; otherwise one screenshot per section.

Claude Code can read image files directly from disk — just say "screenshots are in design/"
and they'll be picked up.
